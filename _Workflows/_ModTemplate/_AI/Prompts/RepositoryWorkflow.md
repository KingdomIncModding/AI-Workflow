# Repository workflow

Read `_Mods/_AI/AGENTS.md` and `_Mods/_AI/_GitHub/REPOSITORIES.md`.
The intended owner is the `KingdomIncModding` organization; your personal GitHub account is only used for authentication.
Use the mod name alone for the repository name, without a `KingdomInc_` prefix.
Read this mod's `mod.json` before remote work. Verify the actual destination and branch before recording a URL; leave unknown values null.
Keep repository, release and SDK links synchronized in metadata, README and Nexus descriptions. Run the Nexus formatter to keep README and DESCRIPTION identical.
For ownership migrations, update mod-local `_AI` workflows first, then shared workflows, then transfer and verify the existing repository before updating metadata and remotes.
Preserve history, repository identity, versions, dependencies and unrelated local edits. Keep `_AI/`, Nexus working files and agent files private.
A migration request authorizes that migration and its link updates only. Other pushes, releases, Nexus uploads and issue operations require a user instruction.
